# 🔢 matrix-calc

Matris toplama, çarpma, transpoz, determinant ve iz hesaplama.

## Kurulum
```bash
cargo build --release
```
## Kullanım
```bash
matrix-calc add "1,2;3,4" "5,6;7,8"
matrix-calc mul "1,2;3,4" "5,6;7,8"
matrix-calc det "1,2;3,4"
matrix-calc transpose "1,2,3;4,5,6"
```
